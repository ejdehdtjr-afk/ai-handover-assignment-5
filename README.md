# 과제 5 — 대화가 끊겨도 이어지는 프로젝트

과제 4의 USD/KRW 환율 기록 정보판을 바탕으로, 두 AI가 같은 검사 기준과 인계 문서를 사용해 하나의 개선 기능을 완성한 결과물입니다.

## 공개 결과

- 결과 화면: https://ejdehdtjr-afk.github.io/ai-handover-assignment-5/
- 인계 문서: [ASSIGNMENT5_HANDOFF.md](./ASSIGNMENT5_HANDOFF.md)
- 공개 화면 소스: [docs/index.html](./docs/index.html)

## 개선 기능

현재 화면에 보존된 1 USD 환율을 사용해 입력한 달러 금액의 예상 원화 금액을 즉시 계산합니다. 빈 입력, 음수, 정상 환율 없음, 장애 후 오래된 환율 사용을 각각 구분해 안내합니다.

## 검사 기준

- 정상 4개: 초기 100 USD, 1 USD, 250.50 USD, 0 USD
- 오류 3개: 빈 입력, 음수, 정상 환율 없음
- 회귀 3개: 장애 5종과 복구, 날짜 기록·차이·검산, 모바일·라벨·상태 전달

최종 결과는 10/10 통과이며, 공개 화면 안에서 검사표와 두 AI의 가린 비교표를 함께 확인할 수 있습니다.

## 30초 확인 방법

1. 공개 화면의 **달러 금액별 원화 환산기**로 이동합니다.
2. 달러 금액을 `100`에서 `1`로 바꿉니다.
3. 예상 원화가 화면 상단의 현재 `1 USD` 환율과 같은 값으로 즉시 바뀌면 통과입니다.

안 될 때는 **정상 조회·복구**를 누른 뒤 금액을 다시 입력합니다.

## AI 3줄

- AI에게 맡긴 일: 환산 계산, 예외 처리, 검사 초안 작성
- 내가 판단한 일: 기능 범위와 6회·30분 상한, 인계 시점 확정
- AI 말을 안 들은 일: 새 API 추가 대신 과제 4의 검증된 환율 재사용
